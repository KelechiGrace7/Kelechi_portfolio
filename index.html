Data analytics & operations

AI Inventory & Product Operations Assistant

Stock and pricing errors are easy to miss when inventory records, the online catalogue and sales history live in different places. This assistant compares them, flags discrepancies, and explains what it found.

  • Compares inventory, catalogue data and sales history to flag stock and pricing discrepancies
  • Analyses sales patterns and recommends stock allocations and operational actions
  • Human-in-the-loop approval step before any decision is acted on
  • Python
  • Streamlit
  • Data analysis
  • Automation

Computer vision & e-commerce · Final-year project

AssistMart: AR try-on fashion e-commerce

Shoppers can’t try accessories on online. AssistMart combines a fashion store with live camera try-on and product recommendations suited to the shopper and the occasion.

  • Virtual try-on for glasses, earrings and lipstick through a live camera feed
  • Facial landmark detection with MediaPipe Face Landmarker
  • Recommendations based on user characteristics and occasion
  • MediaPipe
  • Computer vision
  • Augmented reality
  • E-commerce

Machine learning web application

House Price Prediction

A machine learning model on its own is hard for anyone else to use. I took this one beyond a notebook and deployed it as a web application that predicts a house price from the property details a user enters.

  • Takes user-provided property characteristics and returns a predicted price
  • Flask web app serving a trained model
  • Deployed online so it can be tried without any setup
  • Python
  • Flask
  • Pandas
  • Machine learning
